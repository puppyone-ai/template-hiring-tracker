# Technical exercise reviewer guide: internal-use template

This public document is itself a generic example. In actual use, do not send the internal reviewer guide with the candidate exercise.

| Dimension | Evidence to observe | Actual notes |
| --- | --- | --- |
| Runnable | Setup and startup work according to the README | To record |
| Correctness | Pending returns T-001 and T-004; Project Blue returns T-001 and T-002 | To record |
| Boundaries | Unknown projects, unknown fields, and empty results are explicit; no invented records | To record |
| Implementation | Read-only data, separate configuration and secrets, understandable errors | To record |
| Tests | Normal results and at least one failure case are covered | To record |
| Judgment | Explains choices, limitations, unfinished work, and verification of AI output | To record |

You may ask the candidate to combine two filters live and explain the implementation and personal contribution. Record actual evidence. A person decides whether to proceed; there is no automatic hiring cutoff.
