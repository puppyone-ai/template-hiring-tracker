# 招聘流程

```text
新收到 → 待初筛 → 待约一面 → 一面 → 待约二面 → 二面
      → 待决策 → Offer沟通 → 待入职 → 已入职（移入 91-hired）

人工确认不再推进 → 已归档（移入 90-archive）
```

可以按岗位需要增加三面，或暂停等待核实。阶段值统一使用 [字段规范](../99-system-rules/字段与状态规范.md)，没有第三轮要求时不强制添加。

## 每次变更

1. 记录发生的事实、时间、依据和人工确认内容。
2. 更新总表中的当前阶段及人工结论，AI 不自行作出结论。
3. 在沟通记录或招聘待办填写跟进动作与日期。
4. 重新生成 HTML，检查候选人路径、计数和字段一致。

## 结束流程

人工确认 `pass`、`淘汰`、`候选人退出` 或 `Offer拒绝` 后，按已授权范围将完整行写入归档表，阶段改为 `已归档`，目录移入 `90-archive/<姓名>/`。人工确认已入职后写入已入职表，阶段和结论都改为 `已入职`，目录移入 `91-hired/<姓名>/`。

完成目标表和目录后，从当前表移除对应行并重新编号；修复相对链接并生成 HTML。候选人 ID 和首次入库日期保持不变。

这些变更不会自动发送任何邮件、更新招聘平台或发布资料。
