# 技术练习评审参考｜内部模板

公开仓库中的这份文档也是通用示例。真实使用时不要把内部评审参考随候选人题面一起发送。

| 维度 | 观察证据 | 实际记录 |
| --- | --- | --- |
| 可运行 | 按 README 可完成配置和启动 | 待记录 |
| 正确性 | 待处理返回 T-001、T-004；项目蓝返回 T-001、T-002 | 待记录 |
| 边界 | 未知项目、字段和空结果有明确反馈，无编造记录 | 待记录 |
| 实现 | 数据只读、配置与密钥分离、错误可理解 | 待记录 |
| 测试 | 覆盖正常结果及至少一个异常场景 | 待记录 |
| 判断 | 解释选型、限制和未完成项，能指出 AI 输出的核验过程 | 待记录 |

面试时可请候选人现场组合两个筛选条件，解释实现与个人贡献。评价按实际演示记录，是否推进由人工确认，不设自动录用分数线。
