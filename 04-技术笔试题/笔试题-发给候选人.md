# 技术练习：虚构任务查询助手

> 通用示例题面，与任何公司的业务或内部系统无关。正式使用前由招聘方填写投入时长、提交时间与方式。

## 场景

为一个虚构团队制作任务查询助手。下面是全部演示数据：

| 任务 ID | 项目 | 状态 | 优先级 |
| --- | --- | --- | --- |
| T-001 | 示例项目蓝 | 待处理 | 高 |
| T-002 | 示例项目蓝 | 进行中 | 中 |
| T-003 | 示例项目绿 | 已完成 | 低 |
| T-004 | 示例项目绿 | 待处理 | 中 |

## 要求

1. 提供可运行的命令行或简单界面，支持查询项目、状态和优先级，并返回任务 ID 与结果依据。
2. 能回答“哪些任务待处理？”和“示例项目蓝有哪些任务？”。对不存在的项目、未知字段或空结果给出明确反馈，不编造任务。
3. 原始数据保持只读；补充测试数据时继续使用虚构内容。
4. 提交运行说明、关键测试及简短取舍说明。可使用规则或模型，解释为何选择该方式；若使用外部服务，配置从环境读取，不提交密钥。
5. 说明 AI 工具的使用范围和人工检查方式。
