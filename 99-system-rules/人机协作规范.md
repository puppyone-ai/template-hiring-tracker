# 人机协作规范

| 工作 | AI 可以协助 | 人工确认 |
| --- | --- | --- |
| 建档 | 核验文件、去重、提取事实、整理来源 | 身份冲突与岗位映射 |
| 初筛 | 按岗位标准列出证据、缺口和问题 | 是否进入面试 |
| 面试 | 起草问题、整理笔记 | 评价、结果及下一阶段 |
| 沟通 | 编写邮件草稿和待办 | 收件人、内容、时间与实际发送 |
| Offer | 检查字段完整性、起草文书 | 录用、薪酬、条款、发送 |
| 结束 | 检查表格和链接一致性 | 归档或已入职确认 |

事实注明材料位置；不明确的内容写“待核实”。候选人的自述与已核验事实要区分，AI 判断必须标注 `AI建议` 或 `草稿`。

先从岗位职责和可展示的能力证据提问。不要把与岗位无关的个人信息加入模板，也不要从姓名、照片或背景推断个人特征。

本仓库中的虚构人工结论仅用于展示字段，不构成任何真实录用、拒绝或发送授权。
