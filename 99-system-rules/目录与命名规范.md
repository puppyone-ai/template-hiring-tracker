# 目录与命名规范

| 目录 | 用途 |
| --- | --- |
| `00-console/` | 当前表、浏览版、待办、简短同步日志 |
| `01-roles/` | `<岗位ID>-<English-Role-Name>/`，每岗含 JD、岗位卡、筛选标准 |
| `02-candidates/` | `<岗位>/<姓名>/`，同名时加候选人 ID |
| `03-process-templates/` | 可复用空白文书与流程 |
| `04-技术笔试题/` | 候选人题面及分开的内部评审模板 |
| `05-boss-zhipin/` | 渠道说明和渠道过程记录模板 |
| `90-archive/` | `<姓名>/`，未入职结束的记录及归档表 |
| `91-hired/` | `<姓名>/`，已入职记录及已入职表 |
| `99-system-rules/` | 协作、字段、命名、同步、公开维护规范 |

当前候选人卡链接总表使用 `../../../00-console/候选人总表.csv`；归档、已入职卡使用 `../../00-console/候选人总表.csv`。移动目录后修复卡内链接、表内路径和 HTML。

阶段不作为目录层级。活跃流程中保持候选人目录稳定，只在人工确认归档或入职后移动。

推荐文件：`候选人卡.md`、`面试问题.md`、`沟通记录.md`、`一面记录-YYYY-MM-DD.md`。未知内容用“待核实”，未确认文书标记“草稿”。日期统一 `YYYY-MM-DD`，链接优先使用相对路径。

公开模板中的原始材料以 `示例经历.md` 表达且明确注明虚构，不包含真实附件或真实附件名。真实使用时的原件保留规则只适用于另建的私有工作区。
