# Resume sync rules (not configured)

This public template has no recruiting-platform connection, download directory, scheduled task, or message-sending integration.

Before enabling sync in a private copy, have a person configure the source, allowed roles, material location, and current scope. Connecting to or operating an external system must stay within the user's authorization.

Local intake sequence:

1. Inventory the materials actually supplied, without changing them. Record counts, types, and exceptions rather than relying on a previous estimate.
2. Check that files are nonempty, readable, and of the declared type. Failed text extraction does not mean a file has no content.
3. Check current, archived, and hired records using IDs, identity, aliases, source, and file hashes. Leave conflicts for human verification.
4. Map to an existing role, allocate an unused ID, and copy originals without changing source files or names.
5. Create a candidate card with fact sources. Do not invent missing information. Record the current stage in CSV.
6. Update todos, regenerate HTML, and verify paths and counts.
7. Record successful, duplicate, and exceptional items separately for each source.

If local materials are unreadable, record an exception rather than logging into a platform automatically. Intake does not authorize screening decisions, sending, scheduling, rejection, hiring, or uploading real materials to the public repository.
