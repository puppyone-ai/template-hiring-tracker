# 简历同步规则（未配置）

本公开模板没有连接任何招聘平台或下载目录，没有启用定时任务，也不会发送消息。

如需在私有副本中启用同步，先由人工配置来源、允许处理的岗位、材料路径和本次范围。连接或操作任何外部系统都必须在用户授权范围内。

本地入库顺序：

1. 只读盘点实际提供的文件，记录数量、类型与异常，不用旧数量代替本次范围。
2. 核验文件非空、类型正确且可读；提取失败不等于无内容。
3. 结合 ID、身份、别名、来源及文件哈希检查当前、归档、已入职三处重复；冲突留待人工核实。
4. 映射已有岗位，分配未使用 ID；复制原件，保留来源文件和原文件名。
5. 建立候选人卡，标明事实来源，未知信息不补造；当前状态写入 CSV。
6. 更新待办，重新生成 HTML，核验路径和计数。
7. 在同步记录中记明成功、重复、异常数量。不同来源分别报告。

本地材料无法读取时记录异常，不自动登录平台补救。入库不代表批准筛选、发送、约面、拒绝、录用或上传到公开仓库。
